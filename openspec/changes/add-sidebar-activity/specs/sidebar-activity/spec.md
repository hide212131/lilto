## ADDED Requirements

### Requirement: ベルによる表示切り替え
システムはサイドパネルのベルボタンでチャット一覧とアクティビティ表示を切り替えなければならない（MUST）。切り替え自体では会話選択・既読状態を変えてはならない（MUST NOT）。

#### Scenario: 一覧から切り替えて戻る
- **WHEN** 初期状態でベルを押し、再度押す
- **THEN** アクティビティを表示した後に一覧へ戻り、選択会話と未読状態を維持する

#### Scenario: パネル開閉と再起動
- **WHEN** アクティビティ表示中にパネルを閉じて開く
- **THEN** アクティビティ表示を保持し、アプリ再起動時はチャット一覧で開始する

### Requirement: 更新順に会話の最新内容を表示する
システムは1チャット1行を updatedAt 降順で表示し、タイトルと小さい文字の本文を最大2行で表示しなければならない（MUST）。本文は最新の確定済みかつ空でない表示用メッセージとし、内部進捗を含めてはならない（MUST NOT）。

#### Scenario: 非表示会話へ新しい回答が届く
- **WHEN** 別会話に新しい回答が追加される
- **THEN** その会話が先頭へ移動し、本文と更新時刻と既存の未読表示を更新し、同じ会話の行は増やさない

#### Scenario: 処理中と確定
- **WHEN** 仮メッセージとツール進捗が入り、その後回答が確定する
- **THEN** 仮メッセージと進捗はプレビューに出さず、確定時に本文を更新する

#### Scenario: 長い本文と Markdown
- **WHEN** 長い本文にリンク・コード・HTML 文字列が含まれる
- **THEN** 本文は安全なテキストとして最大2行へ省略し、HTML を実行しない

### Requirement: 保存済み会話のプレビュー取得
システムは未訪問の保存済み会話にもプレビューを取得し、取得を画面内の行から優先し、最大同時数を4に制限しなければならない（MUST）。取得結果が新しいローカル更新を上書きしてはならない（MUST NOT）。

#### Scenario: 再起動後にアクティビティを開く
- **WHEN** 一覧に本文のない保存済み会話があり、アクティビティを開く
- **THEN** 可視行の本文を取得し、読込中表示をプレビューへ置き換え、下へスクロールした行も取得する

#### Scenario: 取得中に回答または削除が発生する
- **WHEN** プレビュー取得中に同じ会話へ新しい回答が届く、または会話が削除される
- **THEN** 遅れて到着した古い結果を適用せず、新しい本文または削除状態を維持する

#### Scenario: 空と失敗の区別
- **WHEN** 会話に本文がない、または本文取得が失敗する
- **THEN** 空なら「まだメッセージがありません」、失敗なら「内容を取得できませんでした」と再試行を表示し、どちらも会話を開ける

#### Scenario: 会話がゼロ
- **WHEN** アクティビティに表示できる会話がない
- **THEN** 「まだアクティビティがありません」と表示する

### Requirement: 既存会話操作とアクセシビリティ
システムは行選択を既存の永続会話再開と既読処理へ接続し、キーボードでも切り替え・選択・再試行できなければならない（MUST）。

#### Scenario: 未読行を開く
- **WHEN** 未読の行をクリックまたは Enter / Space で選ぶ
- **THEN** 対象の会話を開き、既存ルールで既読にする

#### Scenario: キーボードによる切り替え
- **WHEN** ベルへフォーカスして Enter / Space を押す
- **THEN** 表示が切り替わり、支援技術へボタン名と押下状態を伝える

### Requirement: GUI 検証ゲート
実装はライブ画面確認を先に行い、すべての GUI 変更完了後の最終確認として Electron E2E を成功させなければならない（MUST）。

#### Scenario: 完了判定
- **WHEN** 実装を完了として扱う
- **THEN** live-ui-manual-verification による対象機能確認が済み、その後の `npm run e2e:electron` が成功し、`test/artifacts/electron-e2e.png` が生成されている
